# Mistake Log

Use this as your personal review sheet. Keep entries short and practical.

## Day 1

- `append(value)` adds one item to the end of a Python list.
- `total = number` replaces the previous value.
- `total += number` accumulates by adding onto the previous value.
- For highest/lowest problems, initialize with an actual array value like `scores[0]`, especially when negatives are possible.
